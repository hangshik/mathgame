◈ 퍼즐 규칙

  • • 지정된 수량의 전함들이 바다에 숨겨져 있습니다.
  • • 1칸 전함부터 최대 5칸 전함까지 다양한 크기의 배가 등장합니다.
  • • 배의 크기에 맞춰 양 끝단은 반원, 중간은 직사각형 형태로 모양이 자동 표현됩니다.
  • • 게임 시작 시 주황색 테두리의 힌트 타일이 제공되어 위치를 알려줍니다.
  • • 각 행과 열 우측/하단의 숫자는 해당 줄에 존재하는 전함 타일의 총 개수입니다.
  • • 모든 전함은 대각선을 포함하여 상하좌우로 서로 인접할 수 없습니다.
  • • 일반 타일을 클릭할 때마다 [미확인 ➔ 바다 ➔ 전함 ➔ 미확인] 순서로 변경됩니다.
